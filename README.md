# Portafolio Personal

Portafolio web personal desarrollado para presentar mi perfil profesional, habilidades técnicas, experiencia y proyectos realizados en el área del desarrollo de software.

El objetivo de este proyecto es contar con un espacio digital donde pueda mostrar mi trabajo, compartir mis conocimientos y facilitar el contacto con personas interesadas en colaborar o desarrollar proyectos.

## Tecnologías utilizadas

- HTML5
- CSS3
- Bootstrap Icons

## Características

- **Inicio:** presentación personal y resumen profesional.
- **Sobre mí:** información personal, habilidades, formación e intereses.
- **Proyectos:** muestra de proyectos desarrollados y tecnologías utilizadas.
- **Experiencia:** presentación de experiencia y trayectoria de aprendizaje.
- **Contacto:** información de contacto y formulario para enviar mensajes.
- **Diseño responsive:** adaptación a diferentes tamaños de pantalla.

## Instalación y ejecución

1. Clonar el repositorio:

```bash
git clone https://github.com/bohorquedev/Briefcase.git
```

2. Entrar al directorio:

```bash
cd Briefcase
```

3. Abrir el archivo `index.html` en el navegador.

También puedes utilizar la extensión **Live Server** de Visual Studio Code para ejecutar el proyecto durante el desarrollo.
